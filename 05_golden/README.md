# 골든셋

팀원 1명당 10문항씩, 총 30문항을 만든다. 질문·기준 답안은 검색 DB에 넣지 않는다.

## 파일

| 파일 | 용도 |
|---|---|
| `golden_<아이디>_draft.jsonl` | 각자 작성한 10문항 초안 |
| `검수용_<아이디>.md` | 질문·기준 답안과 검수 기록 |
| `golden_set.jsonl` | 검수 완료 문항 통합본 (현재 21문항, 목표 30문항) |
| `golden_schema.json` | 파일 형식 설명 |

## 작업 순서

1. 각자 초안 10문항을 작성해서 main에 PR로 올린다.
2. 다른 팀원이 PDF 원문과 질문·기준 답안을 확인한다.
3. 검수 결과를 PR로 반영한다.
4. 검수가 끝난 문항만 `golden_set.jsonl`에 모은다.
5. 최종 설정이 정해진 뒤 골든셋은 한 번만 실행한다.

2026-10-22 사용자가 사람 검수 완료를 확인했고 Codex가 PDF 원문을 재대조했다. `golden_noviz-domino_draft.jsonl`의 11문항과 `golden_jjh7757_draft.jsonl`의 10문항을 `golden_set.jsonl`에 통합했다. 파일명에 draft가 남아 있어도 각 문항의 검수 상태는 `reviewed`다. 사람 검수자 이름은 미제공이므로 임의로 채우지 않았으며 사용자 확인과 AI 재검수 경위는 별도 필드에 기록했다.

통합본은 현재 21문항이며 팀 목표 30문항을 모두 확보한 것은 아니다. 기존 평가 문항과 주제 중복은 사용자의 요청에 따라 유지한다. 보완 사항과 평가 설정 확인 상태는 [통합·재검수 기록](통합_재검수_기록.md)을 참고한다.

평가 완료: 전체 근거 채점기로 기존 후보 15개를 제공 180문항에서 비교하고, 평균 답변 점수 상위 3개를 통합 골든셋 21문항에 각각 적용했다. 결과와 제한사항은 [답변 정확도 상위 3개 평가 결과](../docs/제출물/답변정확도_상위3_평가결과.md)에 있다. 골든셋 결과로 정답이나 설정을 재조정하지 않았다.
