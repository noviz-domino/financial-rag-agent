# 골든셋 통합·재검수 기록

## 범위와 검수 근거

- 일자: 2026-10-22 (Asia/Seoul).
- 사람 검수 완료는 사용자가 이 대화에서 확인했다. 검수자 이름은 미제공이므로 임의로 채우지 않았다.
- Codex가 현재 작업 폴더의 GOLD-A01~A11, GOLD-B01~B10 총 21문항을 제공 PDF 원문과 다시 대조했다.
- 해당 PDF의 파일명·페이지·조항·표 조건·수치 및 근거 ID를 확인했다. 외부의 최신 제도가 아닌 제공 문서 기준 평가다.
- 기존 평가 문항과 주제가 겹쳐도 유지한다는 사용자 지시를 따른다.
- 전체 목표 30문항과 현재 확보된 21문항은 구별한다. 없는 9문항을 만들거나 검수된 것으로 간주하지 않는다.

## 평가 전 보완

| 문항 | 확인 사항과 조치 |
|---|---|
| GOLD-B01 | 현재 시장 규정으로 오해하지 않도록 제공 용어집 기준의 기본예탁금 질문으로 한정 |
| GOLD-B05 | PDF 112쪽 일반주택·2026년 6월 표 및 76쪽 연소자 기준 확인. 일반주택·부부 합산 시가를 질문에 명시. 월 47만원 확인. 기타 가입 조건의 최종 승인 보장 배제 |
| GOLD-B06 | PDF 16쪽의 2024년 표에 맞춰 '올해'를 제거. 추가공제 없는 일반 카드 사용으로 한정. (2,500만원 - 8,000만원 × 25%) × 15% = 75만원, 한도 250만원 확인 |
| GOLD-B07 | PDF 64쪽 표는 소득 구간이 아니라 신용평점 구간이므로 질문 정정. 보증 32,278억원·보증+융자 비중 49.1% 확인 |
| GOLD-A05·A06 | 문서만으로 확정할 수 없는 이유를 unanswerable_reason에 기록 |
| GOLD-A01~A11 | 근거 설명에 더해 PDF에서 발췌한 짧은 evidence_quote 보완 |

나머지 문항의 핵심 질문·답안·수치·기대 행동은 유지했다. 각 문항의 review_status는 reviewed로 표시하고 사람 검수 확인과 AI 재검수 경위를 별도 필드로 남겼다. 평가 전에 수정한 항목이며 평가 결과를 보고 정답을 바꾼 것이 아니다.

## 통합

golden_set.jsonl에 A 11문항 + B 10문항을 ID 순서로 통합했다. 원본 작성자별 파일과 검수 문서도 같은 내용으로 동기화했다. 질문·기준 답안은 검색 색인에 넣지 않는다.

## 평가 설정 상태

사용자가 과거 성능 상위 3개 설정으로 평가하도록 승인했다. 비교 기록 R3의 검색 Hit@5를 우선하고 동률이면 Recall@5로 정렬해 parent-child 300·400·600자를 선택했다. 벡터 전용은 600자와 Hit@5가 같지만 Recall@5가 낮아 제외했다. 이 순위는 답변 정확도 순위가 아니다.

세 설정은 하이브리드 k=5·embedding-001 768차원·parent_fold=true를 유지하고 현재 Agent를 적용한다. 설정은 configs/golden_agent_parentchild_{300,400,600}.json에 평가 전에 고정했다. 현재 Agent는 구조 변경뿐 아니라 인용·쪽 번호 처리 수정도 포함하므로 그래프만의 인과 효과로 해석하지 않는다.

각 설정을 동일한 21문항에 한 번씩 적용했다(총 63건), 실행·채점 호출 오류 0건. 골든셋 SHA256: 25cf45efa74ca9eb3e2f72d5beb0a4ac58fe7f62f4c954fd2bfb9774869b878e. 결과를 보고 프롬프트·근거·설정을 다시 조정하지 않았다. 이번 평가는 사용자가 요청한 세 가지 고정 구성의 평가이며 단일 최종 구성에 대한 독립적인 미사용 시험으로 주장하지 않는다.

평균 원본 점수(2점 만점)는 300/400/600자 각각 1.3810/1.3810/1.4762, 검색 Hit@5는 세 설정 모두 1.0(19문항 기준)이다. 계산값 검증 오탐과 채점 앞 400자 요약에 따른 환각 오판을 발견했다. 원본 점수는 수정하지 않았으며, 세부 결과·한계는 [평가 보고서](../docs/제출물/골든셋_평가_결과.md)에 기록했다. 다음 개선은 사용자 승인 대기다.
