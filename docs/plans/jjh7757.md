# jjh7757 구현 계획

체크리스트 단계(0~12) 순서로 **실제로 만든 것과 시험한 것** 기준으로 정리했어요. 안 해 본 것은 "미검증"으로 적었어요.
내 코드·결과 위치는 내 작업 폴더 `rag_mini_project/`이고, 청킹 결과는 이 저장소 `chunks/jjh7757/`(PR)에 있어요.

**평가 기준(수치가 나오는 곳 공통)**: 제공 질문·답안 180문항(POS 60, NEG 40, 금융생활 20, 추가 60). 세트별 검색 범위(positive·negative=용어집+표준약관, 금융생활=가이드북, 추가=추가 PDF 6개). 근거 판단 RAG(하이브리드 검색 k=5, Gemini 2.5 Flash). 채점은 LLM 판정(0~2점)이고 **생성과 같은 모델(gemini-2.5-flash)** 이에요. 사람 검증은 하지 않았어요.

2. 채점자를 생성 모델과 다른 모델로 바꾸고 사람 검증 20문항을 넣을지.
3. 추출 결과(특히 Gemini 비전 설명과 표 복원)를 공용으로 쓸지 각자 쓸지. 내 설명에는 사람이 정정한 4건이 반영돼 있어요.
