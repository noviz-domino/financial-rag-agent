# yellowgreenbean 구현·계획

> **현재 상태: 구현·실험 없음.** 이 프로젝트용으로 직접 만든 코드나 실험 결과가 아직 없어요.
> 그래서 모든 항목의 근거 종류는 **문서·의견**이고, 수치·결과는 전부 **미검증**이에요.
> 체크리스트의 ⭐ 수치는 다른 사람의 사전 실험이라 내 근거로 쓰지 않았어요. 장점 칸에서 참고로만 인용했어요.
>
> - 코드 위치: 없음
> - 결과 파일 위치: 없음
> - 조율할 때 이 문서의 선택은 **의견 1표**로만 봐 주세요.
