### 수치 읽는 법
- **〔A〕** noviz 측정: 단어 검색(BM25)만, 정답 근거 ID(`source_ids`)로 채점, 세트별 범위 지킴
- **〔B〕** jjh 측정: 하이브리드 + Gemini로 180문항 끝까지 실행, 정답 **쪽**으로 채점(〔A〕보다 관대), 답변은 같은 AI가 채점
- **〔A〕와 〔B〕는 기준이 달라서 서로 비교하지 않아요.** 같은 기준 안에서도 1~2문항 차이는 "비슷함"으로 읽어요.
- **〔대조〕** 이번 조율에서 같은 쪽·같은 그림을 원본 PDF와 나란히 놓고 눈으로 확인한 결과예요. 표본이 작아서(그림 7개, 표 3쪽, 청크 3종) 방향을 정하는 근거로 쓰고, 구현 후 X1·X2로 다시 확인해요.

## 1. 최종 구성 — 기능별로 더 나은 쪽을 합침

```
PDF 23개
 └ [읽기]   pdfplumber, 펼침면은 좌우 반쪽으로        ← noviz 로더 + jjh 깨진 글자 복구 + 쪽 번호 제거(새로 추가)
 └ [표]     단순한 표 → pdfplumber 그대로            ← noviz
            병합 칸·복잡한 표 → 칸 채우기 + 행 머리글 반복   ← jjh
            그래도 실패 → Gemini (병합 칸 채우기 규칙 포함)
            긴 표 → 행 단위로 나누고 머리글 반복        ← jjh
 └ [그림]   후보 찾기 → 좌표 규칙                    ← noviz (jjh 레이아웃 결과로 놓친 그림 1회 점검)
            숫자 그래프·표·절차도 → 구조화 설명(값 전부) ← noviz
            화면 캡처·작은 글자·일러스트 → 짧은 요약     ← jjh
            고장·의심 → 길이 검사 + 숫자 검사 → 사람 확인 ← noviz 자동 검사 + jjh 사람 검수
 └ [정답]   정답 근거 ID 연결 + 쪽 적중 둘 다 계산       ← noviz + jjh
 └ [자르기] 용어 1개 / 조항은 ①②항 경계에서만 / 가이드북은 제목 단위 + 짧은 절 합침  ← jjh 규칙
            청크 필드·정답 ID·조항·그림 참조 링크·parent    ← noviz 구조
            섹션 경로(문서 > 장 > 절)                      ← jjh
 └ [저장]   gemini-embedding-001 + Chroma, 바뀐 청크만 다시 임베딩  ← jjh 캐시 방식 + 결정(Chroma)
 └ [검색]   하이브리드 BM25(Kiwi) + 벡터, RRF 60, k=5, 범위 강제   ← jjh 코드 + 결정
 └ [답변]   근거 판단 → 답변 2단계, 7가지 대응 행동, JSON 출력     ← jjh + noviz·yellow 형식
 └ [Agent]  최소 그래프 먼저, 링크 따라가기는 2차                ← noviz·yellow 설계 + jjh 근거 판단
 └ [평가]   jjh 평가 루프 + noviz 검색 지표 + 규칙 채점 + 다른 AI 채점·사람 20문항
```

| 사용 | 설정 확정 후 1회 | 동의 | 같음 | 1회. 결론은 제공 180문항으로, 골든셋은 실패 사례 확인용 |

## 5. 회의에서 물어볼 질문
검색 방식·저장소·그림 설명·Docling은 이미 정해졌어요. 남은 건 아래 다섯 가지예요.

**1. 담당을 이렇게 나눠도 될까요?**
- 왜 묻나: 정해야 세 명이 동시에 만들기 시작할 수 있어요.
- 제안: noviz님은 읽기·그림·자르기, jjh님은 표·검색·답변·채점, yellow님은 Agent와 직접 만드는 문제 18개. Agent에 "관련 조항을 따라가서 더 찾아보는 기능"까지 넣을 시간이 있는지도 같이 정해요.

**2. 다들 윈도우 PC인가요?**
- 왜 묻나: 그림 속 글자를 읽는 도구(Windows OCR)가 빠르고 무료지만 윈도우에서만 돼요.
- 모두 윈도우면 그대로, 아니면 다른 도구(EasyOCR)로 통일해요.

**3. 글자를 뽑을 수 없는 페이지가 몇 쪽이나 되나요?**
- 왜 묻나: 많으면 무거운 프로그램(Marker)이 다시 필요할 수 있어요.
- 몇 쪽 안 되면 그림 처리 방식으로 해결해요. 구현 첫날 세어 봐요.

**4. 답변 채점은 어떤 AI가 할까요? 사람 확인은 누가 할까요?**
- 왜 묻나: 답을 만든 AI가 스스로 채점하면 점수를 후하게 줄 수 있어요.
- 제안: 같은 키로 쓸 수 있는 gemini-2.5-pro로 채점하고, 20문제는 사람 두 명이 직접 채점해서 AI 채점이 믿을 만한지 확인해요.

**5. API 비용은 누가 낼까요?**
- 왜 묻나: 180문제를 한 번 돌릴 때마다 AI를 수백 번 불러요. 각자 무료 한도가 달라서 한 명에게 몰릴 수 있어요.
- 제안: 평소엔 각자 키, 많이 돌리는 실험만 공용 키.
