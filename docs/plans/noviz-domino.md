# noviz-domino 구현·계획

> 체크리스트(`docs/구현_결정_체크리스트.md`) 0~12단계 순서. **0~5단계는 실제로 만들고 측정했고, 6~12단계는 설계만 한 상태(미검증)** 예요.
> 근거 종류: `측정`(같은 질문 세트·같은 채점으로 잰 수치) / `시험해 봄`(일부 표본을 눈으로 확인) / `문서·의견`(안 해 봄)

### 측정 조건 (아래 수치는 전부 이것)
- 검색: **BM25 + Kiwi 형태소** (LLM·임베딩 없음, 비용 0) — `python -m src.check_chunks`
- 질문: 기본 positive 60(용어집+약관만 검색) / 가이드북 20(가이드북만) / 추가 60(추가 PDF만). negative 40은 검색 채점 대상 아님
- 정답: 제공 답안의 `expected_source_ids`(251개)가 청크의 `source_ids`에 있으면 적중
- 가이드북은 **1문항 = 0.05**, 추가 1문항 ≈ 0.017, 기본 1문항 ≈ 0.017 → 0.05 이하 차이는 "비슷함"으로 읽기

## 9. Agent
기본 RAG(검색 1회 → 답변)와 **같은 검색 도구·같은 LLM**을 쓰고, 흐름만 다르게 해서 "구조의 효과"를 비교할 수 있게 설계했어요.

```
START → route ──┬─ unsafe/부적절 ─────────────→ refuse ──────────→ END
                ├─ 조건 부족(내 계좌, 최신 금리) → clarify/abstain ─→ END
                └─ 답변 대상
                     ↓
              plan_queries (원 질문 + 용어 확장 1~2개)
                     ↓
                 retrieve (hybrid, scope 강제) ←──────────┐
                     ↓                                     │
                  grade (근거 충분? 부족한 정보는?)          │
          ┌──────────┼───────────────┐                     │
       충분      링크로 보완 가능   부족 & 재시도 < 2 → rewrite
          │          ↓
          │     expand (get_parent / follow_ref: "제7조에 따라", "그림 Ⅲ-9")
          │          ↓
          └──→ generate → verify (인용이 검색 결과에 있나, 숫자가 근거에 있나)
                              ├ 통과 → END
                              ├ 실패 & 재생성 < 1 → generate
                              └ 실패 → abstain(근거 부족 명시) → END
```
| 항목 | 내 선택 | 근거 종류 | 수치·결과 | 장점 | 걱정되는 점 | 다른 안도 괜찮은가 |
|---|---|---|---|---|---|---|
| 9-1 형태 | **LangGraph** StateGraph | 문서·의견 | – | 그래프 = 구조도 제출물 | 의존성 | 직접 while 루프 |
| 9-2 route | LLM 구조화 출력(유형·안전·범위) + 키워드 규칙 보조 | 문서·의견 | – | negative 대응 분리 | 오분류 시 과잉 거절 | 규칙만 |
| 9-2 grade | 청크 묶음을 한 번에 판정, `missing_info` 출력 | 문서·의견 | – | 호출 1회 | – | 청크별 판정 |
| 9-2 expand | **청크 링크(parent·조항·그림 참조) 따라가기** — 우리 청킹의 차별점 | 문서·의견 | 링크 102+98개 이미 있음 | 다중 조항 질문, 그림 밖 예외 문장 | – | – |
| 9-2 verify | 규칙(인용 존재·숫자 원문 대조) 먼저, LLM 생략 | 문서·의견 | – | 비용 0 | 의미 오류는 못 잡음 | LLM verify |
| 9-3 종료 | 재검색 최대 2, 재생성 최대 1, LLM 호출 상한 8 | 문서·의견 | – | 비용 상한 | – | – |
| 9-4 State | `question, scope, route, queries, retrieved, context, grade, missing_info, retry, answer, behavior, citations, trace, llm_calls, search_calls, tokens_in, tokens_out` | 문서·의견 | – | 비용 비교 필드 포함 | – | – |
