- 통합본: `05_golden/golden_set.jsonl`, GOLD-A 11문항 + GOLD-B 10문항 = 21문항. 목표 30문항의 완성을 의미하지 않는다.
- SHA256: `25cf45efa74ca9eb3e2f72d5beb0a4ac58fe7f62f4c954fd2bfb9774869b878e`.
- 과거 R3 검색 Hit@5, 동률 시 Recall@5로 선택: parent-child 300(0.9730), 400(0.9662), 600(0.9595). 벡터 전용은 600과 Hit@5 동률이나 Recall@5가 낮다. 과거 최종 답변 정확도 상위 3개라는 뜻은 아니다.
- 현재 Agent + 하이브리드 k=5 + embedding-001 768차원 + parent_fold=true. 자식 청크 크기만 300/400/600으로 다르다. expand=false.
- 생성 gemini-2.5-flash, 채점 gemini-2.5-pro, temperature=0. 각 설정 21문항 1회, 총 63건. 가짜 AI 결과가 아니다.
- 실행 전 설정을 고정했다. 평가 후 질문·기준 답안·모델·프롬프트·검색·검증 코드는 변경하거나 재실행하지 않았다. 현재 Agent에는 과거 그래프 변경 외에 인용 처리 수정도 포함되어 있어 그래프만의 효과로 볼 수 없다.

## 자원 사용과 비교 한계

| child 크기 | 생성 논리 호출 | 생성 캐시 적중 | 검색 호출 | 생성 입력/출력 토큰 | 채점 논리 호출 | 채점 캐시 적중 | 문항당 생성 시간 |
|---|---|---|---|---|---|---|---|
| 300 | 46 | 0 | 22 | 97,023 / 57,174 | 21 | 1 | 14.99초 |
| 400 | 43 | 27 | 21 | 94,716 / 51,243 | 21 | 3 | 5.90초 |
| 600 | 45 | 31 | 21 | 94,601 / 55,768 | 21 | 4 | 5.67초 |

캐시를 포함한 논리 호출은 생성 134회 + 채점 63회 = 197회다. 캐시 적중 66회를 제외한 캐시 미적중 논리 호출은 131회다. 질문 임베딩과 API 재시도 횟수는 이 수에 포함하지 않으며 재시도 횟수는 별도로 집계되지 않는다. 토큰 집계에는 캐시된 응답의 과거 사용량도 들어가므로 실제 이번 청구액으로 환산하지 않는다.

300자는 workers=2, 나머지는 workers=1로 실행했고 세 실행이 시간상 겹쳤다. 캐시도 서로 공유했다. 시간·처리량 차이를 모델이나 청크 크기만의 성능 차이로 해석하지 않는다. 단일 채점 모델, 설정별 1회, 21문항, 채점 앞 400자 제한이 있는 결과다. 골든셋에 인젝션 문항이 없어 인젝션 처리율은 측정되지 않았다.
