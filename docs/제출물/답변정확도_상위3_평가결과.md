# 최종 답변 점수 기준 15개 후보 비교와 상위 3개 골든셋 평가

평가일: 2026-10-22 (Asia/Seoul). 사용자가 전체 180문항으로 정확하게 비교하도록 승인했다. 15개 후보 × 180문항 = 2,700건을 비교하고, 답변 평균 점수 상위 3개에 골든셋 21문항씩 총 63건을 평가했다. 1건의 모델 JSON 형식 실패는 문항을 제외하지 않고 0점으로 포함했다. 골든셋 63건에는 실행·채점 오류가 없다.

## 비교 조건과 선정 기준

- 모든 후보에 현재 Agent를 적용했다. 검색/청킹의 기존 단일 요소 변경 설정 15개를 비교했으며 모든 조합을 탐색한 것은 아니다. 기본 RAG와 Agent를 함께 섞어 순위를 매기지 않았다.
- 제공 질문: positive 60, negative 40, life_guide 20, additional 60 = 180. 질문별 검색 범위와 기준 답안은 동일하다.
- 생성 gemini-2.5-flash, 채점 gemini-2.5-pro, temperature=0. 임베딩은 별도 후보인 embedding-2 외에는 embedding-001 768차원이다.
- 평균 답변 점수(0=틀림/핵심 없음, 1=부분 정답, 2=핵심 정확)를 주 지표로 고정했다. 동률이면 2점 문항 수, 환각 수, 입력 토큰, 후보명 순으로 정한다. 검색 Hit@5로 후보를 선정하지 않았다.
- 완전 정답률은 별도로 2점 문항 수 / 전체 문항 수로 표시한다. 평균 점수를 단순 정답률로 환산하지 않는다.
- 각주 처리는 기존 loading.superscript_ratio=0.65 및 기존 색인을 그대로 사용한다. 작은 각주 위첨자 번호 제거 로직이 적용된 기존 데이터이며 각주 본문 전체 삭제나 제거 전후 실험이 아니다. 작은 실제 숫자가 같이 지워지는 F1 개선도 반영하지 않았다.
- 채점기는 검색 청크 앞 400자 대신 전체 텍스트와 모든 페이지 번호를 전달하는 full-retrieved-v2로 통일했다. 회귀 테스트를 포함한 전체 테스트 94개가 통과했다.
- 생성·채점을 문항별로 병렬화했다. 각 설정 workers=8, 동시 설정 수 3. 논리·프롬프트·데이터는 실행 전에 고정했고 실행 중 바꾸지 않았다.

## 상위 3개 골든셋 결과

골든셋은 A 11문항 + B 10문항, 총 21문항이다. 사람 검수 완료는 사용자 확인, AI 재검수와 통합 경위는 05_golden/통합_재검수_기록.md에 기록했다. 후보 선택에 골든셋 점수를 사용하지 않았고 골든셋 결과로 설정을 다시 조정하지 않았다.

| 제공 세트 순위 | 후보 | 제공 평균 / 2 | 골든셋 평균 / 2 | 골든셋 완전 정답 | 골든셋 Hit@5 |
|---|---|---|---|---|---|
| 1 | 제목 접두어 임베딩 | 1.5167 | 1.4286 | 12/21 (57.14%) | 100.00% |
| 2 | parent-child 300자 | 1.5056 | 1.3810 | 11/21 (52.38%) | 100.00% |
| 3 | parent-child 600자 | 1.5000 | 1.3810 | 11/21 (52.38%) | 100.00% |

검색 Hit@5는 근거 ID가 있는 19문항 기준이며, 답변 점수·정답률은 21문항 기준이다. Hit@5=100%는 모든 필요한 근거가 온전하거나 답변이 모두 정확하다는 뜻이 아니다.

골든셋은 이전 검색 상위 3개 평가에도 이미 사용됐다. 이번 결과를 처음 보는 독립 최종 시험으로 주장하지 않으며, 21문항 차이만으로 최종 구성의 일반적 우수성을 확정하지 않는다.

## JSON 형식 실패 처리

recursive 300자의 POS049가 원 실행과 동일 설정 재시도에서 모두 'Unterminated string' 오류를 반환했다. 해당 문항을 제거하거나 정상 후보만으로 비교하지 않고 원본의 0점을 180문항 분모에 유지했다. 원본 results/scores/summary는 수정하지 않았다.

- 원 실행: runs/answer_rank_20261022_provided_exp1a_recursive_300_100/.
- 재시도: runs/answer_rank_20261022_provided_exp1a_recursive_300_100_retry1/.
- 오류 처리 경위: runs/answer_rank_20261022/output_failure_policy.json, 해당 실행의 documented_output_failures.json.
- 최초 보수적 검사에서 순위 집계가 중단된 진행 기록도 provided_progress.before_output_failure_review.json에 보존했다.
- 문항 수와 점수는 그대로 두고 검증 절차만 이어가도록 continue_answer_comparison.py를 사용했다. 통신·할당량 오류와 누락은 여전히 순위 확정을 막도록 했다.

## 사용량과 재현

기록된 생성 논리 호출 6,115회(캐시 1,059회), 채점 논리 호출 2,762회(캐시 134회)다. 생성+채점 입력 19,307,989토큰, 출력 14,740,252토큰이다.

토큰과 호출 집계에는 캐시된 응답의 과거 사용량이 포함된다. 실패 문항의 예외 경로는 실제 사용량을 0으로 기록하며 재시도·임베딩 요청도 위 집계에서 제외되어 있으므로 실제 청구액이나 전체 네트워크 요청 수로 환산하지 않는다. 후보 간 캐시 적중과 동시 실행의 차이 때문에 시간도 순수 처리속도 순위로 해석하지 않는다.
