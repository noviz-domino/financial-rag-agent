**해석 (정확도 vs 토큰, 규칙: 차이가 오차 안이면 토큰이 적은 쪽)**

2. **청킹**: parent-child가 가장 높지만(0.973) 기준 대비 +0.027로 오차 안이고 근거 토큰이 **1.8배**(3,000 vs 1,669). 구조형 800은 기준과 Hit@5 같고(0.946) 토큰 14% 적음 → **구조형 800이 효율 최선**. 글자 수 자르기는 겹침을 고친 뒤에도 구조형보다 낮음(0.885~0.926), 단 300자는 토큰이 가장 적음(826).
3. **k**: k=4(0.926, -0.020)·k=3(0.912, -0.034)은 기준과 오차 경계. 토큰은 20%·41% 감소. 같은 k로 비교하려면 기준(k=5)의 상위 3개·4개만 본 지표가 더 공정함(미실시).
4. **임베딩 모델**: embedding-2(0.932)는 001(0.946)보다 낫지 않음(오차 안, 약간 낮음). 001 유지. 제목 붙이기(실험 4)는 Hit@1 +0.034(0.804)·MRR 소폭 상승이지만 Hit@5는 같음.
5. **추천 기준 설정**: 구조형 **800자** + 하이브리드 + embedding-001 + **k=5** (Hit@5 동일, 토큰 -14%). 토큰을 더 줄이려면 k=4 (-20%, Hit@5 -0.02)를 답변 점수로 확인한 뒤 결정. 단 이것은 **검색만**의 결과이고, 답변 품질 영향은 시험 실행으로 확인 필요 (사용자 결정).

**임베딩 호출**: 문서 임베딩은 청킹 변형·모델마다 새로 만듦(001: 약 1.5만 개 텍스트, 배치 100개씩 약 150회 / embedding-2: 텍스트별 호출 1,523회). 질문 임베딩은 모델당 180개. API가 임베딩 토큰 사용량을 돌려주지 않아 토큰은 집계 못 함. 같은 설정으로 `build --reuse`를 다시 돌리면 **새 임베딩 호출 0번**(확인함).

## R4. D34 Agent 재시험 (2026-10-21)
**조건**: R2와 같은 진짜 Gemini·하이브리드 k=5, D34 구현(route 삭제) 뒤 Agent, `--workers 2`. 실행 ID `pilot_rag`(기본 RAG, 코드 그대로라 응답이 모두 캐시 → 비용 0) · `pilot_agent`(D34 Agent). **30문항**: R2의 40문항 중 positive 10 · negative 10 · 가이드북 10. 추가 PDF 10문항은 R2에 ID가 줄여 적혀 있어(`HP01` → 실제 `ADD-HP01`) `--case-ids`에서 빠졌어요. **표본이 작아 방향만 보는 용도**(문항 1개 = 3.3%p).

|---|---|---|---|
| 검색 Hit@1 / Hit@5 (n=25) | 0.60 / 0.88 | 0.64 / 0.84 | 0.486 / 0.686 (40문항) |
| 답변 점수 (0~2) | **1.33** | 1.10 | 1.03 |
| 필수 내용 포함률 | **0.65** | 0.54 | 0.38 |

| 인용 정확도 | **0.62** | 0.49 | 0.38 |
| 인젝션 처리 (6문항) | **4/6** | 3/6 | 2/6 |

| 오류 | 0 | 1 (POS045, F15) | 0 |

**과다 거절 원인 (Agent가 답해야 할 문항을 abstain 한 6건, trace 확인)**: 6건 모두 **grade 는 answer/correct·근거 충분으로 판단**했고, 답변 뒤 **verify(규칙 검사)** 에서 불합격 → 재작성도 불합격 → abstain. 기본 RAG에는 verify 가 없어 같은 문항에 답함.
| 원인 | 문항 | 기록 |
|---|---|---|
| 출처를 `.pdf` 없이·한 괄호에 여러 개 써서 파일명 앞 번호(01·07·15 …)가 "근거에 없는 숫자"로 잡힘 | POS052·057·060 | F14 (고침) |
| 질문 속 숫자로 계산한 값(600, 83.33, 7,200 …)이 문서에 없어 "근거에 없는 숫자" | POS073·080 | F16 (결정 필요) |
| 쪽 번호 `8,9` → `int()` 오류로 문항 오류(빈 답 = 거절로 집계) | POS045 | F15 (고침) |
