# 개발 기록 — 제출 문서 작성용 자료 모음

새 결정을 하거나 실험 결과가 나오면 **그때그때 해당 파일에 추가**해요. 날짜와 근거를 꼭 같이 적어요.

> 다른 세션(사람·AI)에게 문서 작성을 맡길 때: "`docs/개발기록/` 폴더를 참조해서 ○○ 제출 문서를 써줘"라고 하면 돼요.

## 적는 규칙
- **수치에는 조건을 붙여요**: 어떤 질문 세트, 어떤 채점 방법(정답 근거 ID 기준인지 쪽 기준인지), 진짜 AI인지 가짜 AI인지.
- **근거 종류를 구분해요**: `측정`(숫자로 잼) / `대조`(원본과 눈으로 비교) / `의견`(아직 검증 안 됨).
- 가짜 AI(`--dry-run`, `USE_API=False`) 결과는 **성능 근거로 쓰지 않아요.**
- 실험 결과는 `runs/{실험ID}/`가 원본이에요. 여기에는 요약과 해석, 실험 ID를 적어요.
