# jjh7757 청킹 결과

23개 PDF(`01_data`)에서 직접 추출한 텍스트(쪽 단위 블록 JSONL)를 청킹한 결과예요. 원본 데이터는 수정하지 않았어요.

## 파일
| 파일 | 내용 | 청크 수 |
|---|---|---|
| `structured.jsonl` | 구조형 청킹 최종본(내 작업 폴더의 `structured_v5`와 같음) | 1,386 |
| `recursive_500_50.jsonl` | 재귀 청킹 비교본(500자, 겹침 50) | 1,493 |
| `chunking.py` | 두 전략을 만드는 코드 | |

청크 필드: `chunk_id`(`파일|p쪽|c번호`), `file`, `page`, `pages`, `text`, `text_raw`, `doc_title`, `group`(glossary/terms/guide), `section`, `kind`(term/article/body/table/figure), `strategy`. 이미지가 있는 청크는 `image` 경로가 있지만 이미지 파일은 올리지 않았어요.

## 전략
| 대상 | structured | recursive_500_50 |
|---|---|---|
| 용어집 | 용어 하나 = 청크 하나(글꼴 크기로 용어/정의 구분) | 쪽 본문을 문단→줄→공백 순으로 분할 |
| 표준약관 | 조항(제N조) 단위, 길면 항(①②…) 경계로 분할하고 조 제목 반복 | 위와 같음 |
| 가이드북·추가 | 글꼴 크기로 찾은 제목 단위, 짧은 절은 합침(100자 미만), 표는 별도 청크 | 위와 같음 |

공통: 쪽을 넘는 청크는 만들지 않아요. 표는 Markdown, 중복 청크는 제거했어요.
